## 路线对比矩阵（销阻塞-1）

评分：◎优 ○可 △差 ✕不可行（括号内为依据事实编号）

| 维度 | A-first：ArkTS 原生直上 | B-first：HAP+WebView 壳先行 | **C：两步走（采纳）** | R2：DSH 插件形态 |
| --- | --- | --- | --- | --- |
| 实现成本 | ✕ 最高：ArkTS 全栈 + SSH/终端全自研（8） | △ 壳易引擎难：壳依赖 HAP 通道未通（8），引擎难题不变 | ○ 分期付款：Phase 1 用现成运行时（3） | ◎ 复用宿主 node（4） |
| 运行风险 | ○ 原生最稳（建成后） | △ 通道未通前无法验证 | ○ Phase 1 风险已知可控（3/6） | △ 与宿主同生共死（评审 P2） |
| 演进性 | ◎ 终态即起点 | ○ 壳可复用 | ◎ 每步可交付、可回退 | ✕ 绑死 DSH 生态，非独立应用 |
| 运维成本 | ○（建成后单包分发） | △ 双世界（壳+引擎） | △ Phase 1 人肉运维（见部署生命周期节） | ◎ 宿主管 |
| 回退难度 | ✕ 沉没成本最大 | △ | ◎ 每夜 commit 可回退 | ○ |

**A-first 否决理由**：事实 8 构建/安装双通道未考古即全仓押注 ArkTS，冷启动最慢且首月无任何可运行交付，违反"每夜必有可验证产出"纪律。
**B-first 否决理由**：壳先行但 HAP 通道未通（事实 8）时壳无从验证；引擎难题（node 崩溃/Python 边界）一件不少，只是被壳遮住。
**R2 否决理由补披露**：Phase 1 引擎当前实测挂在 DSHM 进程树下（评审 P2），"非 DSH 生态"的优势要到自启/分发打通（部署生命周期节）才成立——R2 与 C 的真实差距当前只有五十步，这正是我们把自启列为正式攻关的原因。

## 决策（草案 r2）：两步走

### Phase 1（立即启动）：Python 引擎 + Web/PWA 前端（架构同构于 hexhub）

- 引擎：python3 stdlib（engine/server.py 已点火）；**SSH 栈选型裁决移交 [ADR-0003](ADR-0003-SSH栈与通信通道选型.md)（Go 静态二进制为主候选）**。
- 通信通道：终端链路需低延迟双向——若维持 Python 引擎则 stdlib 手写 RFC6455（约 200 行）或退化 SSE+POST（延迟双输，不推荐）；若 ADR-0003 落子 Go 引擎则用现成 ws 库。**通道裁决并入 ADR-0003。**
- 交付形态：本机浏览器访问 `http://127.0.0.1:8977`——**"演示实证"**（口径修正，见部署生命周期节），非安装验收。

### Phase 2（并行成长线）：ArkTS/ArkUI 原生化 + 引擎存续攻关

- 每夜一个鸿蒙主题；HAP 构建通道攻关（服务器 hvigor + 签名 + 本机安装通路考古）。
- **引擎在 HAP 中存续（蓝军升格的正式攻关项，与部署通道并列）**，三候选：
  a) CPython 随 znCRT HAP 打包（DSHM 先例证明可行、亦证明不便宜——事实 7）；
  b) **HAP 壳 + 随包 Go 静态引擎 ELF**（busybox/DSHM execve 先例——事实 5/7/10，若 ADR-0003 落子 Go 则此项与 Phase 1 引擎同体，当前最优先）；
  c) ArkTS 全量重写引擎（终态选项，成本最高）。

## 风险与边界（销阻塞-3 + 建议-1）

1. **SSH 栈（口径修正）**：宿主 Python 仅纯 Python 包可用（事实 10）；paramiko 硬依赖 cryptography（C/Rust 扩展）⇒ **大概率死**（事实 9 实装实验实录，退出码记入 ADR-0003 首条证据）；ADR-0003 候选已重排：Go 静态二进制为主候选。
2. **GPL 两个 hexhub 分流**：① hexhub GitHub 仓库（GPL-3.0）代码可参考/移植，znCRT 同协议并保留原版权声明；② **hexhub.cn 发布件（含新版前端 bundle）仅限行为/协议分析，零拷贝**；其反编译产物与原始取证 JS（`hexhub-*.js`）**永不入 znCRT 仓库**（.gitignore 显式拦截）；③ vendored 第三方件随附 LICENSE 与来源清单（docs/NOTICE.md，引入时建）。
3. **性能预算（首版宽松但必须有数）**：终端按键回显 P95 ≤ 80ms（局域网实测法：录像帧计数）；SFTP 单流 ≥ 5 MB/s（dd 100MB 实测）；并发会话 ≥ 4 路不劣化。差异矩阵 P0 项验收时附实测数。
4. 浏览器直连 localhost 是 Phase 1 形态，不算"原生鸿蒙应用"；Phase 2 完成前不宣称最终验收达成。
