# ADR-0001 立项与对标口径

- 状态：**已接受**（2026-10-28，Damon 指令立项）
- 决策人：Damon；牵头：啾啾（Lead）

## 决策

1. 立项 **znCRT**：对标 hexhub 的开源鸿蒙 SSH/SFTP/数据库管理客户端。
2. **License = GPL-3.0**：与 hexhub 同协议，无论走"参考开源 UI 层"还是"clean-room 重写"都无合规风险；对社区也最诚实。
3. **"一模一样"的口径**：功能基线逐项对齐（`01-hexhub-baseline.md` → `02-diff-matrix.md` P0/P1 全绿）+ 本机部署运行；UI 仿其布局与交互，不追求逐字节复刻。
4. **REA（逆向）边界**：只用于行为/协议/格式分析（发布件、配置、凭据存储），不拷贝闭源代码与资源。
5. 节奏：每晚 23:30 夜间会话，每日差异比对，每夜必有 commit + journal。

## 备选方案（已否决）

- 逐字节像素级复刻：验收不可测、平台差异（Windows 挂载盘符等）不可达，否决。
- MIT/Apache 协议：若未来任何程度移植 hexhub 开源代码会违约，风险不值，否决。

## 后果

- znCRT 全程 GPL-3.0，衍生作品同协议。
- Windows 专属功能（挂载盘符等）在矩阵中标 ➖ 并定义鸿蒙等效物，不视为不对齐。

## 待决（ADR-0002 议题，2026-10-28 23:30 首次夜战评审）

znCRT 技术路线：A) ArkTS 原生应用（成长价值最高）B) WebView 混合（复用 xterm.js 生态，对齐最快）C) 先 Web 后原生的两步走。约束：本机 node 损坏、HAP 构建通道未通、服务器可用。
